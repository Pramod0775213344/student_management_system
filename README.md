# Student Management System

A full-stack Student Management System built with the MERN stack (MongoDB,
Express, React, and Node.js). It provides authentication and role-based
management for students, teachers, academics, attendance, examinations, and
results.

## Deployment

- Frontend: React/Vite application hosted on Vercel
- Backend: Node.js/Express API hosted on an Oracle Cloud VM
- Database: MongoDB

The frontend and backend are deployed separately. Configure the frontend API
base URL with `VITE_API_BASE_URL` and configure the backend environment
variables in `backend/.env` on the Oracle Cloud VM.
